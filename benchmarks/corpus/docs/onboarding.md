# Welcome to the team

## Day one

1. Get your laptop from IT and sign in to the password manager.
2. Clone the repository and run `make bootstrap`. It installs tools and starts the local stack.
3. Run `make seed` to load sample accounts and lists.
4. Pick a ticket labelled `good-first-task` and pair with your buddy on it.

## Week one

Read the architecture overview, shadow the on-call engineer for a day and ship one small change.
