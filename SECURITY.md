# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/Shizoqua/hermes-scout/security/advisories/new)
instead, with steps to reproduce and the version you tested. You will get a reply within a week.

## What the plugin does with your data

See the [Disclosure](README.md#disclosure) section of the README: which files it reads, what it sends
to the embeddings endpoint you configure, and what it stores on disk.

## Supported versions

Security fixes go into the latest release.
